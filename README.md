Модульный, быстрый и детерминированный установщик операционной системы **ElyOS** (дистрибутива на базе Arch Linux). Написан на современном C++ с использованием реактивного терминального интерфейса (TUI).

## Особенности архитектуры

- **Строгий C++ без тяжелых рантаймов:** Нулевая зависимость от Python или Electron на установочном носителе. Минимальное потребление ОЗУ и быстрый старт.
- **Движок состояний (Finite State Machine):** Детерминированный конвейер шагов установки с аппаратной защитой от перехода к неподготовленным этапам и поддержкой безопасного отката назад.
- **Реактивный TUI-интерфейс:** Построен на базе библиотеки [FTXUI](https://github.com/ArthurSonzogni/FTXUI). Поддерживает управление стрелками, мышью, горячими клавишами и работает внутри изолированного альтернативного буфера терминала.
- **Изолированный Process Runner:** Кастомный модуль выполнения процессов ядра Linux с принудительной фиксацией локали `LANG=C` для защиты от сбоев парсинга.
- **Детальное логирование:** Потоковая запись хода установки с секундными метками в локальный файл журнала.

## Стек технологий

* **Язык:** C++17
* **Система сборки:** CMake (>= 3.20) + Ninja
* **Интерфейс:** FTXUI
* **Парсинг данных:** nlohmann_json
* **Системный базис:** Arch Linux

## Сборка и запуск

### Требования к зависимостям (Arch Linux):
```bash
sudo pacman -S base-devel cmake ninja git
```

### Сборка:
```bash
cmake -S . -B build -G Ninja
cmake --build build -j$(nproc)
```

### Запуск:
Установщик требует прав суперпользователя для инспекции и разметки блочных устройств:
```bash
# Обычный интерактивный режим
sudo ./build/bin/ElyOS_Installer

# Режим расширенной отладки с выводом в лог
sudo ./build/bin/ElyOS_Installer --debug
```

Лог выполнения сохраняется в файл: `elyos-installer.log`.
